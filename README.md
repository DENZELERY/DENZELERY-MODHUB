# DENZELERY MODHUB

Официальный онлайн-каталог модов DENZELERY MODHUB.

## Структура

- `catalog.json` — единый публичный каталог модов, который загружает Hub.
- `references/` — JSON-эталоны платных модов (без платных ZIP).
- `media/<mod-id>/` — обложки и скриншоты; папки создаются редактором при публикации.
- **GitHub Releases** — ZIP-архивы бесплатных модов.
- Видео — внешние HTTPS-ссылки.

Публикацией управляет DENZELERY MODHUB Owner Editor. Покупаемые ZIP-архивы размещаются отдельно, например на Boosty.

Пока старые JSON-эталоны сохранены также в корне для совместимости со ссылками, опубликованными ранее. Удалять их можно только после обновления каталога и приложений.
